# Lingo v0.1.0 — Public preview / 公开预览版

Lingo translates the text you already wrote with your own LLM provider, in a lightweight Rust desktop app.

Lingo 是一个轻量 Rust 桌面应用，使用你自己的大模型服务翻译已经写好的文本。

## English

This **first public preview** includes:

- A workbench for translating a selected passage or a whole draft, with optional replacement and copyable results.
- English, Traditional Chinese, Japanese, other presets, and custom target languages.
- Configurable OpenAI-compatible Chat Completions, defaulting to DeepSeek `deepseek-flash`.
- Experimental Option-drag and **⌘⇧L** integration, target checks before writing, and menu-bar pause, cancel, and guarded undo.
- macOS Keychain storage, command-line translation, and provider diagnostics.

**Install:** extract the ZIP, drag **Lingo.app** into **Applications**, then open **偏好设置** (Preferences) and save your own API key. Try the workbench first. To try native selection translation, enable **Accessibility** and **Input Monitoring** for Lingo in **System Settings → Privacy & Security**, then restart.

The binary is **Apple Silicon only**, declares macOS **12.0+**, and was tested on **macOS 26.4.1 arm64**. It is ad-hoc signed and **not Apple-notarized**; macOS may block the download. [Building from source](https://github.com/Finn-Fengming/Lingo/tree/v0.1.0#run-from-source) with Rust 1.88+ is also available. There are no Intel, Windows, or Linux binaries in this release.

**Verified:** 19 unit/mock tests, 4 explicit live DeepSeek tests, and manual workbench checks passed. GitHub CI passed stable Rust formatting/lint/tests and all-target compilation on Rust 1.88. **Cross-app gestures, replacement, undo, and changed-target protection have not been verified end to end.** Editor compatibility varies; use the workbench when native selection is unsupported. See [test evidence](https://github.com/Finn-Fengming/Lingo/blob/v0.1.0/docs/testing.md).

No credentials are bundled. Selected or pasted text goes to your configured provider; its policies and billing apply. Lingo keeps no persistent translation history. The native guard temporarily holds the field's full text locally; only the selected passage is sent. Cancel discards a result but cannot recall a sent request; undo requires an unchanged target.

## 简体中文

**首个公开预览版**包含：

- 翻译工作台：支持选区或完整草稿翻译、可选替换及复制译文。
- 英文、繁体中文、日语等预设及自定义目标语言。
- 可配置的 OpenAI 兼容 Chat Completions，默认使用 DeepSeek `deepseek-flash`。
- 实验性 Option 拖选和 **⌘⇧L** 集成、写回前目标检查，以及菜单栏暂停、取消和撤销。
- macOS 钥匙串存储、命令行翻译及模型诊断。

**安装：**解压 ZIP，将 **Lingo.app** 拖入 **应用程序**，打开 **偏好设置** 并保存自己的 API Key，先在工作台试译。如需试用原生选区翻译，在 **系统设置 → 隐私与安全** 中为 Lingo 开启 **辅助功能** 和 **输入监控**，然后重启。

二进制包**仅支持 Apple Silicon**，声明最低系统版本为 **macOS 12.0**，实际测试环境为 **macOS 26.4.1 arm64**。应用采用 ad-hoc 签名，**尚未经过 Apple 公证**，macOS 可能阻止打开下载包。也可以使用 Rust 1.88+ [从源码构建](https://github.com/Finn-Fengming/Lingo/blob/v0.1.0/README.zh-CN.md#本地运行)。本次不提供 Intel、Windows 或 Linux 二进制。

**已验证：**19 项单元/模拟服务测试、4 项真实 DeepSeek 测试及工作台手动检查通过；GitHub CI 通过 stable Rust 的格式/静态检查/测试，以及 Rust 1.88 的全部目标编译检查。**跨应用手势、替换、撤销及目标变化保护尚未完成端到端验证。** 编辑器兼容性存在差异，不支持的场景请使用工作台。详见 [测试记录](https://github.com/Finn-Fengming/Lingo/blob/v0.1.0/docs/testing.md)。

安装包不包含密钥。选中或粘贴的文本会发送给你配置的服务商，遵循其数据处理和计费规则。Lingo 不保存持久化翻译历史；写回检查会在本机临时保留全文快照，仅将选区发送给模型。取消无法撤回已发请求；原生撤销要求目标保持不变。
